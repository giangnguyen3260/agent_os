## API

Base `/api/v1/organizations/{organizationId}/organization-map`, ApiResponse data envelope. Both endpoints use read-only REPEATABLE_READ and existing NewTeamDraftService.authorize(org,human,false,false). Unknown/duplicate query parameters rejected400, page lexical digits0..100000, query normalized using Java String.strip before checking max200 UTF-16 characters; escaped literal case-insensitive LIKE search on Teams name/purpose and Agents name/role. The UI sends raw search text so Java normalization is authoritative. UUIDs accepted only canonical lower-case RFC versions1..5. Generic scoped missing-Team404; unauthorized403. Transport authentication precedes controller checks: anonymous/disabled/stale credentials may yield401, nonmember403, authorized invalid query400; malformed organization paths may be denied403 by the existing scope filter before canonical controller validation. Stable order lower(name),id.

GET base accepts only page(default0),query(defaultempty),status(optional DRAFT/ACTIVE/ARCHIVED). Result exact keys `{organizationId,name,teamTotal,agentTotal,unassignedTotal,teams}`. Totals are organization-wide persisted counts; teamTotal must equal teams.total only without filters. teams page exact `{items,page,size,total}`, size20. Item exact `{id,name,purpose,status,managerAgentId,managerName,managerUnavailable,agentCount,intake}`. purpose/intake nullable stored values. Manager identity/name returned only if pointed Agent has same organization AND Team; otherwise both null and managerUnavailable=true when a nonnull invalid pointer exists. agentCount counts same-org assigned Agents; no joins may multiply counts. Organization counts exclude invalid foreign-Team attachments; unassigned means actual team_id IS NULL. No hidden fabricated root manager or human owner.

GET `/agents` accepts only teamId(optional canonicalUUID; absent means Unassigned),page(default0),query(defaultempty). Exact result `{organizationId,teamId,team,items,page,size,total}` size20, nullable teamId/team for Unassigned. team is the same Team item shape, loaded by scopedID independently of the overview page/filter. Team may change between separate requests; UI labels reads as current snapshots, never an atomic cross-request graph. Missing/foreign Team404. Item exact `{id,name,role,level,status,reportsToAgentId,reportsToName,reportingUnavailable}`. A reporting target is disclosed only when same-org, same Team (including both unassigned) and not self; invalid nonnull targets null/redacted and reportingUnavailable=true. Flat reporting labels, no recursive graph traversal or inferred authority; cycles between valid scoped Agents cannot recurse or hang. Safe nullable/unknown legacy strings remain visible as recorded values, never activation eligibility. No foreign identifiers, configuration/prompt bodies, human accounts or audit payloads in responses.

## URL and paging decisions

UI query keys are teamId,teamPage,query,status,agentPage,agentQuery; unknown/duplicate keys are invalid. Absent teamId selects Unassigned, never an invented first-Team selection. Selecting a Team or Unassigned resets Agent page/query only. Team filters reset Team page and Agent page/query while retaining explicit selection; selection can remain outside filtered Team results because the inspector is independently scoped. Agent search resets Agent page only. Clear filters resets everything to Unassigned. Pagination permits out-of-range empty pages with retained total. Browser Back/Forward reloads URL state. Visible-tab return and focus both revalidate current session/workspace even during pending reads, clearing private data before new authority checks.
