## API and availability

GET `/api/v1/organizations/{organizationId}/agents/{agentId}/permissions`, no query parameters (unknown/duplicate400). Canonical lower-case RFC UUID versions1..5; transport auth/scope may reject401/403 before controller validation. Current enabled credential-version-matching ADMIN or MEMBER may read every Agent lifecycle, using AgentDraftService.authorize(org,human,false,false). Authorized missing/foreign Agent404, unauthorized403, stale/disabled session may401. Read-only REPEATABLE_READ; no business writes, audit insertion, history, grants, session authority change or migration. No additional write route; existing activation remains blocked.

ApiResponse data exact11keys `{organizationId,agentId,name,status,configurationRevision,checkedAt,teamState,team,configurationPresent,sourceStatus,requests}`. configurationRevision actual stored integer0..2147483647; checkedAt actual UTC server ISO observation time. teamState ASSIGNED|UNASSIGNED|UNAVAILABLE. team exact `{id,name,status}` only when same-org assigned Team exists; otherwise null, never expose a foreign/raw pointer. configurationPresent reflects actual existence of agent_draft_config, including empty/null requested fields. Missing configuration does not materialize default rows. Read only Agent identity/revision, scoped Team context and requested model/tools/skills; exclude contract/prompt/config bodies unrelated to this screen and human/grant records.

sourceStatus is UNAVAILABLE because this release has no authoritative Agent authorization source or evaluator. It describes implemented infrastructure, never an editable readiness flag or seeded business value. Do not return an empty effective-grant set, zero grant counts, allowed/denied values or an invented issuer/scope to stand in for an absent source. No positive evaluator adapter, fake ready provider or client-derived role/grant source is introduced. Future positive evaluation requires a separate contract and authoritative integration; do not silently enable it by changing this constant.

requests is exactly3 ordered records MODEL,TOOLS,SKILLS. Each exact `{kind,configured,effective,grantedBy,scope}`; configured is the actual nullable stored string, unchanged (including empty/newlines/whitespace). effective/grantedBy/scope must all be null while sourceStatus UNAVAILABLE. These are three known configuration domains, not enumerated granted resources. Empty requested text means empty request, not denial. Legacy missing configuration yields configured null, configurationPresent false; no defaults. Recognized or unknown stored lifecycle strings remain recorded labels; ACTIVE alone does not establish executable permission.
