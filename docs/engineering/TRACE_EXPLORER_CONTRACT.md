## Authorization and source

Current enabled credential-version-matching organization ADMIN/MEMBER may read using the same read invariants as MissionCreateService.authorize(org,human,false,false). That helper is package-private; the new trace service applies equivalent organization/account/current-membership predicates locally, without changing shared authorization. No actor identity, payload, prompt, input/output, exception text, human grant or credential is queried/returned. REPEATABLE_READ read-only. Existing /error denial and shared security stay unchanged. No business writes/audit/receipts.

Visible events are a bounded subset of audit_events: same organization, at least one non-null mission_id/task_id, every non-null reference resolves within the organization. A task resolves to a same-org Mission, and its team_id equals that Mission's non-null team_id; that Team must exist in the organization. If both event references exist, they must agree on Mission. A mission-only event may have null Team; a non-null Mission Team must resolve same-org. Invalid, foreign, dangling, inconsistent references exclude the entire event from list/count/detail. Event actor_type/event_type are recorded opaque labels, not actors or outcome/status. Unknown values remain text. Organization-only audit events are outside this read view, not evidence of zero organization activity. Never parse payload.

## API

GET `/api/v1/organizations/{organizationId}/trace-events`
- Query allowlist only `q,missionId,taskId,page`, each at most once. q optional literal case-insensitive event_type substring, Java strip, max100 Unicode code points; literal %, _ and escape characters are escaped. Blank becomes empty. missionId/taskId optional canonical lowercase RFC4122 UUIDv1–5. Empty/invalid UUID400. page default0, canonical decimal0..100000; size fixed20. Unknown/duplicate params400, including size/sort. Filter IDs match visible projected rows; foreign/nonexistent IDs yield empty list and no metadata (not a scope-existence oracle). Both filters intersect. Org outer authorization may401/403 before controller validation.
- data exact `{organizationId,generatedAt,runtimeStatus,items,page,size,total}`; runtimeStatus exactly `UNAVAILABLE` describes absent runtime source. generatedAt current server UTC ISOInstant, fractional seconds0..9. total counts exactly the filtered visible subset, no derived runtime counts. page/size actual requested/fixed20. Stable order created_at DESC, id ASC; all count/page source reads share a transaction. Beyond-last page returns empty items with actual total.
- Each item exact `{id,eventType,actorType,createdAt,team,mission,task}`; explicit nulls always present. team null or exact `{id,name}`. mission always exact `{id,title}` (resolved from event mission or task's mission); task null or exact `{id,title}`. Metadata actual safe same-org rows, no raw pointers. Database timestamp converted to UTCInstant. Do not expose actorId, payload, runId, correlationId, output or status guessed from eventType.

GET `/api/v1/organizations/{organizationId}/trace-events/{eventId}`
- No query params. Canonical lowercase UUIDs. data exact `{organizationId,generatedAt,runtimeStatus,event}`, event exact same item. Unauthorized403/401; missing/foreign/excluded event404. Detail is re-read with current authorization, not raw audit payload. No write endpoint.
