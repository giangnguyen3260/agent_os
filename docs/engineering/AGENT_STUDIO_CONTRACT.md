## Boundaries

Only ADMIN may edit a DRAFT agent. Current members may read all statuses. Name, role, team, description, level, autonomy and status are read-only here. Editable fields: responsibilities, expectedInput, outputFormat, acceptanceCriteria, model, skills, tools, limits (existing requested free text), plus nullable structured concurrency, maxTokensPerRun, monthlyBudget. Model/tool/skill fields remain requested configuration. Structured limits are saved configuration, not enforced runtime limits. Activation, provider calls, grants and sandbox execution remain unavailable and explicitly explained. Do not alter old create/detail response shape or existing baseline browser locators.

## HTTP and transaction

GET `/api/v1/organizations/{org}/agents/{agent}/configuration`: member-readable, current enabled credential-version membership checks, scoped404, no organization write locks. Response data is `{agent: AgentDraftResponse,revision:integer,concurrency:integer|null,maxTokensPerRun:integer|null,monthlyBudget:number|null,currency:'USD'}`. Read agent+config+revision consistently in repeatable-read transaction. No effective grants implied.

PUT same path: fresh enabled account/version ADMIN, CSRF, required UUID Idempotency-Key; full allowlisted request `{expectedRevision,responsibilities,expectedInput,outputFormat,acceptanceCriteria,model,skills,tools,limits,concurrency,maxTokensPerRun,monthlyBudget}`. Required contract text stripped1..4000; optional text null/omitted equal otherwise exact max2000. Numeric fields must be JSON numbers, not strings/boolean/fractional integer. expectedRevision required integer0..2147483646. concurrency null or integer1..1000; maxTokensPerRun null or integer1..2000000; monthlyBudget null or number0..1000000 with max2decimal places, normalizedscale2. Unknown security fields never mass-assigned. Empty optional text may stay empty; UI blank=>null. Reject no-op saves400. UI does not issue write until diff confirmation.

Response200 first save and replay, same GET shape. Revision increases by1; server-owned agent identity/team/status unchanged. 409 CONFIGURATION_CONFLICT for stale revision, AGENT_NOT_EDITABLE for non-DRAFT, IDEMPOTENCY_CONFLICT for same key different canonical body. Receipt scoped org/account/agent/key, body hash includes expectedRevision, original response retained. Failed save must not leave partial configuration, increment, version or receipt. Concurrent different keys with same expectedRevision => one save, one stale409. Identical key/body => same response/version.
