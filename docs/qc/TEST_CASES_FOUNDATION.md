D4: valid/invalid JSON, missing/null/unknown fields, oversized/boundary values, injection strings, unsafe URLs and long Unicode text. Limits come from approved contracts.
D5: browser viewports 390/768/1440 CSS px plus 600/1024 and landscape/zoom; delayed A response/event after switching to B.
D6: controlled failing/passing quality fixtures in an isolated CI test branch/job only; no fixture changes authorized by this documentation task.
